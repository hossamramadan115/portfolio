This is a simple static portfolio website for **Hossam Ramadan**.
It includes:
- Home (hero with profile image and socials)
- About
- Projects (two example projects)
- Contact
- Responsive layout with a purple/black theme

## How to use

### Option A - Run locally
1. Unzip the project.
2. Open `index.html` in your browser.

### Option B - Publish on GitHub Pages
1. Create a new repository on GitHub named `portfolio`.
2. Push the project files to the `main` branch.
3. On GitHub: Settings → Pages → Source → Deploy from a branch → Branch: `main` → Root. Save.
4. Your site will be available at:
   `https://<your-github-username>.github.io/portfolio/`
